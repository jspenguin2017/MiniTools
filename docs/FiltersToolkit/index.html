Text Transform: Links to Comma-Separated Domain Array

The output array is sorted, but duplicates are not removed.

The first link on each line will be extracted; extra text in front of links is ignored.

Domain tools accept ASCII hostnames with at least two dot-separated labels, IPv4 addresses, and bracketed IPv6 addresses. Hostname labels allow letters, digits, and hyphens, with no leading or trailing hyphens. Labels are limited to 63 characters and hostnames to 253 characters. Empty labels, underscores, trailing dots, wildcards, and negation are not supported.

Warnings will be generated for lines that contain more than one link or do not contain any valid links.

Enter one HTTP or HTTPS link per line, separated from surrounding text by whitespace. Punctuation attached to a hostname is invalid. Internationalized URL hostnames are converted to Punycode.

Text Transform: Unmerge Comma-Separated Domain Array

        

          From the first nonblank line, remove domains that are contained in subsequent lines. Enter plain domains
          without URLs, ports, or paths. Use Punycode for internationalized names. Spelling and case are preserved; only
          exact matches after trimming are removed.
        

        
Each match removes one occurrence of a domain. Any remaining duplicate entries are preserved.

        
The output array is sorted.

        
Invalid entries are skipped on every line. Warnings will be generated for invalid or unmatched entries.

        
        
Enter one comma-separated domain array per line.
