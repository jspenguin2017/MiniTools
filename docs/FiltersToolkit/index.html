Text Transform: Links to Comma-Separated Domain Array

The output array is sorted, but duplicates are not removed.

The first link on each line will be extracted; extra text in front of links is ignored.

Warnings will be generated for lines that contain more than one link or do not contain any valid links.

Enter one HTTP or HTTPS link per line.


      


      

        
Text Transform: Merge Comma-Separated Domain Arrays

        
The output array is sorted. Duplicate and invalid entries are removed.

        

          Enter plain ASCII hostnames with at least two dot-separated labels, or IPv4 addresses. Use Punycode for
          internationalized names. URLs, trailing dots, wildcards, and negation are not supported.
        

        
Warnings will be generated for entries that are removed.

        
        
Enter one comma-separated domain array per line.

        
        
        
        

        

      


      

        
Text Transform: Unmerge Comma-Separated Domain Array

        

          From the first nonblank line, remove domains that are contained in subsequent lines.
        

        
Each match removes one occurrence of a domain. Any remaining duplicate entries are preserved.

        
The output array is sorted.

        
Warnings will be generated for entries that are not matched.

        
        
Enter one comma-separated domain array per line.
